# Training data

Training datasets are intentionally excluded from this repository.

To reproduce the ML pipeline, place appropriately licensed copies at:

- `phishing_urls.csv` - PhiUSIIL-style data with `URL` and `label` columns (`1` legitimate, `0` phishing)
- `nsl_train.txt` - NSL-KDD training split
- `nsl_test.txt` - NSL-KDD test split

Review the source, license, integrity, and privacy properties of every dataset before use. Never place customer URLs, scan results, credentials, or production traffic in this directory.
