# Security policy

## Reporting a repository vulnerability

Use GitHub's private vulnerability-reporting or security-advisory feature for vulnerabilities in SentinelScan itself. Provide the affected component, expected and observed behavior, impact, and safe reproduction steps using synthetic data or a system you control.

Do not upload suspected malware, real customer data, credentials, scan results, or target details to a public issue. This repository is not a sample-submission service.

## Scope

This policy covers the source and documented configuration in this repository. It does not authorize testing GitHub, VirusTotal, ClamAV, Nmap, Metasploit, model/data providers, or any third-party system. This project does not operate a bug-bounty program and no reward is promised.

## Supported version

Only the latest commit on the default branch is supported.
